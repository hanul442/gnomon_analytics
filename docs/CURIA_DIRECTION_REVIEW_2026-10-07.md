# CURIA 방향성 점검 · 2026-10-07

기준 방향: 개인화된 AI 위원회와 근거를 놓고 토론하는 투자 리서치 서비스. 시장 데일리 → 관심 자산 → 담당자 입장과 반론 → 질문 → 판단 변경 조건 → 후속 검증이 한 흐름으로 연결되어야 한다. 숫자와 사실은 요금제에 따라 달라지지 않고, 공개 범위·분석 깊이·질문 권한을 구분한다.

## 이번 작업에 반영한 항목

- CURIA 로고·서비스명, 조회 기간과 봉 주기의 구분, 중복 봉 주기 선택 통합, 지표 메뉴 안 시나리오 표시, 수익률 눈금이 같은 모멘텀 게이지.
- 홈 검색 아래 큰 배너, 공시 레이더 옆 작은 데일리 버튼. 시장 위클리 생성·홈 노출·공개 아카이브 제거.
- 기존 인포그래픽을 코스피·코스닥·코인·ETF에 재사용. 기존 전문가 11명의 개별 판단과 상호 반박·레드팀 12차례 토론, 공통 토론 렌더러를 적용.
- 데일리 무료 요약, Plus 상세 열기(10크레딧)와 질문, Pro/Max/alpha 전체 열람. 서버 권한 검사와 상세 분석 암호화. 기존 토론 입력·전문가 선택·계정 질문 기록 재사용.
- 홈 요금제 안내를 실제 API 권한에 맞춤. Pro 크레딧 안내 300→400 수정. 시나리오 표시 설정도 기존 계정 설정 동기화 대상에 추가.
