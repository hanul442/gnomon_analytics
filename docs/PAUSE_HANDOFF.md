## 3. 한서가 직접 할 수 있는 것 (Claude 없이)

모두 GitHub 저장소 → Settings → Secrets and variables → Actions → **Variables**에서 해요.

| 하고 싶은 것 | 변수 | 값 |
|---|---|---|
| AI 다시 켜기 | `GNM_AI_BUDGET_USD` | 한 달 달러 (예: `15`). 다 쓰면 그달 나머지는 AI 해설만 쉬고 데이터·채점은 계속 |
| AI 위원회를 싼 모델로 | `GNM_COMMENTARY_MODEL` | `claude-sonnet-5-5` (Opus의 절반 값). 비우면 Opus |
| SNS 자동 게시 끄기 | `PROMO_POST` | `off` |

- **SNS 검수**: `promo-review` 라벨 이슈에 `올려`라고 댓글을 달면 올라가요. 답을 안 하면 아무것도 안 올라가요 (그래도 괜찮아요).
- **Anthropic 사용 한도**: console.anthropic.com → Settings → Limits에서 월 사용 한도를 걸어 두면 코드 상한이 고장 나도 그 이상은 안 나가요. Claude 구독 해지와 API 요금은 **따로**예요. 구독을 끊어도 API 요금은 계속 나가요.
- **뭔가 깨졌을 때**: 사이트 데이터는 GitHub Actions → Daily report → Run workflow로 다시 돌릴 수 있어요. 빨간불이 며칠 이어져도 사이트는 마지막 성공한 날 그대로 보여요.
- **비상 정지**: Actions → Daily report → `···` → Disable workflow. AI 요금도 함께 멈춰요.
