# Alpha v2.0.0

큰 변화는 첫째 자리, 중간 변화는 둘째 자리, 작은 수정은 셋째 자리입니다. 기존 버전은 Git 기록을 기능별로 묶은 회고이며 과거 배포 태그가 아닙니다. 사이트의 `updates.html`에서 전체 기록을 확인합니다.

## 사용자 동작

- 질문은 `/ask/stream` SSE로 텍스트를 즉시 표시하고 최종 답변·차감 정보를 확정합니다. 연결 종료 후에도 서버 작업은 지속합니다.
- 리포트 요청은 `/reports`에서 데이터 확보·크레딧 예약 후 Cloudflare Queue로 생성합니다. 새로고침·창 닫기 후 작업 ID로 재개하며 자동으로 페이지를 이동하지 않습니다.
- 같은 사용자·종목·종류·데이터의 중복 요청은 재차 차감하지 않습니다. 시작 실패·AI 실패·15분 이상 정체는 크레딧을 반환합니다. 실패한 요청은 재요청 가능합니다.
- 프로·맥스·알파는 기존 심층 리포트를 추가 열기 비용 없이 조회합니다. 플러스의 개별 열기와 기존 요청자 권한은 유지됩니다. 서버가 권한을 확인한 뒤에만 실제 본문을 반환합니다. 잠금 모자이크에는 가짜 블록만 들어갑니다.
- 리포트 없는 종목도 요약, 차트, 기술, AI 위원회, 수급, 실적, 뉴스·공시 일곱 탭을 유지합니다. 차트와 기술은 별도 탭이며 전략은 접어서 볼 수 있습니다. 코인 수급은 거래량·OBV·A/D·VWAP으로 대체하고 코인 차트에는 업비트 1·5·15·60분봉과 일봉 전환을 제공합니다. 확보된 공개 자료는 표시하고 미생성 분석에는 생성 버튼을 보여 줍니다.
- AI 조건 생성은 지원 필드·시장·현재 조건을 전달하고 서버에서 결과를 검증합니다. 사용자가 확인·적용·수정·저장합니다. 지원하지 않는 조건이나 JSON 오류는 크레딧을 반환합니다.
- 토론 아래 질문 폼과 입력창 옆 + 버튼의 전문가 선택 대화상자가 있습니다. 모바일에서는 대화상자 내부만 스크롤합니다.
- v2.1.0부터 강제 대기는 없습니다. 실제 요청이 300ms 이상 이어지면 로딩을 표시합니다. 빠른 캐시 검색·필터·탭은 즉시 표시하며 실제 데이터 대기에만 로딩을 표시합니다. 백그라운드 가격/이벤트 수집은 제외합니다. 메뉴 자체의 열기·닫기는 즉시 반응합니다.

## Thinking Orbs

원본: https://github.com/Jakubantalik/thinking-orbs

MIT 라이선스의 원본 engine과 presets를 `vendor/thinking-orbs`에 보관했습니다. 고정 커밋은 `UPSTREAM_COMMIT`, 라이선스는 `LICENSE`에 있습니다. React 대신 DOM adapter를 사용합니다. `npm run build:orbs`로 번들을 재생성합니다. 한 루프에서 화면에 보이는 canvas만 30fps로 그리고, 모션 줄이기 설정은 정지 프레임을 표시합니다.

## 운영 반영

API 워크플로가 `0006_report_jobs.sql`을 적용하고 `gnm-reports` Queue를 생성합니다. Cloudflare 토큰에 Queue 설정 권한이 필요합니다. Worker에 `ANTHROPIC_API_KEY`가 없거나 Queue가 미설정이면 차감 전에 거절합니다. Pages 빌드도 함께 반영해야 공개 research 입력 및 새로운 UI가 배포됩니다. 전 종목 신규 요청은 확보된 가격 기록을 사용하며 수급·실적·뉴스가 없으면 판단을 보류합니다. 최신 데이터 기준일을 생성 결과에 표시합니다.

라이브 결제 연동은 기존 프로젝트 범위 그대로이며, 이 변경은 서버의 요금제 권한을 기준으로 접근을 제어합니다.

업비트 분봉 명세: https://docs.upbit.com/kr/reference/list-candles-minutes . UTC 절대 시각으로 저장하고 KST로 표기하며, 체결 없는 구간을 임의로 채우지 않습니다. 조회 결과는 Worker에서 30초 캐시합니다.
