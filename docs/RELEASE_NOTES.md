# Alpha v2.1.0 — 2026-10-06

리포트가 없는 주식·ETF·코인도 기존 리포트와 같은 템플릿으로 생성합니다. 차트 도구와 기술 지표를 동일하게 제공하고, 미생성 AI 시나리오·표결·토론은 같은 위치에서 모자이크로 표시합니다. 기술 탭의 피보나치·볼린저·RSI·MACD·ATR·지지·저항을 누르면 차트 탭에서 해당 지표가 켜집니다. 짧은 설명과 기술로 돌아가기 버튼을 함께 표시합니다.

시나리오를 펼치면 최근 가격과 20거래일 예상 범위를 함께 표시합니다. 차트 탭에서도 강세·기본·약세를 전환하고 비교할 수 있습니다. 예상 범위가 없는 경우 만들지 않으며, 잠긴 리포트의 시나리오 범위는 차트에 노출하지 않습니다. 음영은 범위이며 미래 가격 경로가 아닙니다.

토론 입력창을 토론 안에 합쳤습니다. + 버튼에서 답변자를 고르고 ➤로 전송하며, 입력창 아래에 크레딧 비용이 표시됩니다. + 내 전문가에서 이름·분야·분석 관점·답변 스타일을 계정에 저장하고 삭제할 수 있습니다. 저장은 무료이며, 질문은 기존 전문가 요금과 Pro 이상 권한을 적용합니다.

AI 조건 생성은 입력창 옆 ✦ 버튼으로 간소화했습니다. 버튼의 기능은 접근성 이름으로도 안내하며, 비용은 아래에 표시합니다. 홈 필터와 저장·적용 버튼을 줄이고 반복 설명과 전체 토론·상세 근거는 접어두었습니다.

최소 2초 강제 로딩을 제거했습니다. 캐시된 결과·필터·탭은 즉시 표시하고, 300ms 이상 걸리는 실제 요청에만 로딩 표시를 합니다.

## 이번 버전의 변화

| 기능 | 변경 내용 | 사용법 |
|---|---|---|
| 분석 화면 | 차트와 기술을 별도 탭으로 분리 | 차트에서 가격 흐름을 보고 기술 탭에서 지표와 전략 확인 |
| 코인 차트 | 일봉과 1·5·15·60분봉 전환 | 차트의 주기 버튼 선택 |
| 코인 거래 흐름 | 거래량, OBV, 매집/분산, VWAP 표시 | 수급 탭 확인. 투자자별 순매수 자료가 아닌 거래 지표 |
| 위원회 토론 | 전체 발언자를 기본 표시 | 필요할 때 발언자 필터 사용 |
| 토론 참여 | 토론 바로 아래 입력창과 전문가 목록 팝업 | 질문 입력 → 옆 + 버튼으로 답변자 선택 → 비용 확인 → 보내기 |
| AI 스크리너 | 자연어로 조건 제안 | 원하는 특징 입력 → 조건 확인·수정 → 적용 → 필요하면 저장 |
| 채팅 | 답변 스트리밍과 Thinking Orbs | 질문 전송 후 진행 상태와 도착한 답변 확인 |
| 공통 로딩 | 화면·필터·데이터 준비에 최소 2초 표시 | 로딩 완료 후 결과 확인. 백그라운드 가격 갱신은 제외 |
| 심층 리포트 | 기존 리포트를 요금제·개별 권한으로 열람 | Pro·Max·알파 또는 기존 열람 권한으로 열기 |
| 미생성·잠금 영역 | 메뉴 유지와 모자이크 표시 | 공개 데이터 확인 후 리포트 생성 또는 권한 안내 이용 |
| 모바일 | 가로 넘침 방지와 팝업 내부 스크롤 | 작은 화면에서도 같은 메뉴와 입력창 사용 |
| 안내 | 버전 배너·사용법·릴리스 노트 | 배너의 새 사용법 또는 릴리스 노트 링크 선택 |
