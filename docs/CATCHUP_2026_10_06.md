## Scenario regression and v2.4.1 correction

#82 deliberately replaced condition prices with forecast midpoint distances. #83 added analyst-target fallbacks. A bullish target from an old report can sit below today's live price, which makes a large negative percentage beside “bull” confusing. Analyst targets also have no guaranteed 20-session horizon.

Show the stored `scenario.trigger` as the primary price. Legacy reports can use an unambiguous, explicit upper/lower exit in the **base scenario's invalidation** (e.g. 255,750원 위로 안착 / 222,000원 아래로 밀리는 경우), labeled as that source. This is a transition reference, not a guaranteed direction. Never use bull/bear invalidation, analyst targets or generic support/resistance as entry thresholds. Ambiguous or absent conditions stay textual.

Keep the future range as secondary information. Label committee ranges, analyst target ranges and volatility reference ranges separately. Percentages remain secondary and use the report's analysis close, with the analysis date and price stated. Preserve Claude's chart/menu/notification work rather than restoring stale pre-Claude files.

## INVALID_OUTPUT follow-up — v2.4.2

The new screenshot exposes INVALID_OUTPUT. The deployed SDK's `BetaMessageStream.finalMessage()` returns raw text content and does not run the output-format parser. Claude's #82 changed `messages.parse()` to streaming but still required `response.parsed_output`. Thus a valid JSON message could deterministically fail with UNPARSEABLE_OUTPUT.

v2.4.2 parses the assembled text once and validates it with the existing deep/brief Zod schema. It preserves refusal/max-token checks, invalid-format failures, billable usage and credit refunds, without a second AI request. Regression checks cover valid brief/deep raw streams, malformed JSON, schema mismatch, refusal and truncation, plus actual SDK SSE assembly with a mocked HTTP response. A production paid generation has not been invoked during these checks. New event/theme requests are planned in EVENTS_AND_THEMES_PLAN.md and are not described as implemented.
