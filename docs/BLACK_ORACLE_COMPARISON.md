> - BOT: `black_oracle_bot` main `62c1790`

> 이미 가져온 것은 [DESIGN.md](DESIGN.md) §5.1·§7에 있고, 이 문서는 **그 뒤의 차이와 앞으로 가져올 것**을 정리해요.

## 0. 한 장 요약

- **제품이 달라요.**
  - BLACK ORACLE은 "근거 → 판단 → 전략 → 리스크 → 실행 → 결과"를 재현하는 **AI 투자 운영체제**예요(자동매매 + 리포트).
  - GNM은 **매매하지 않는 리서치 대시보드**예요. 공개 데이터로 계산하고 주 1회 AI 리포트를 써요.
- **GNM이 앞선 것:**
  - 전 종목(약 2,700) 매일 계산
  - 운영비 0원에 가까운 정적 배포
  - 성적표 공개
  - 요금제 원가 검증
- **BLACK ORACLE에서 아직 못 가져온 핵심 원칙:**
  - 판단과 분포를 섞지 않기(다수결 금지)
  - 근거 종류 표시(사실·추론·가정·반대 근거·데이터 공백)
  - 예측이 쓴 근거의 버전 기록
  - 데이터 신선도 배지 통일
  - 기능 상태 어휘
- **가져올 것 우선순위:**
  - P1(유료 전): 위 원칙들과 AI 사용 원장
  - P2: 섹터 강도, 판단 재구성 화면, 결과 기여 분석, 전략 검증 강화, 용어 설명(Edu)
  - P3: 투자자 프로필, Globe
- **가져오지 않을 것:** 실제 매매, 브로커 연결, 진입·손절·목표가 계획, 24석 위원회, 커뮤니티

## 3. GNM이 BLACK ORACLE보다 나은 점 (지켜야 할 것)

1. **범위:** 리포트가 없는 종목까지 약 2,700종목을 매일 계산해요. BO는 지정 자산만 다뤘어요.
2. **운영 단순성:** 서버·DB 없이 정적 배포로 돌아가요. 실패는 이슈로 알려요. 운영비는 AI 비용 정도예요.
3. **비용 통제:** AI를 주 1회만 쓰고, 단계도 나눴어요(Opus 5개, Haiku 35개). 요금제 원가율은 테스트로 강제해요.
4. **공개 채점:** 성적표를 무료로 공개하고, 틀린 기록도 지우지 않아요.
5. **읽기 쉬운 표현:** 의회·한 줄 요약·시장 온도처럼 5초 안에 읽히는 화면이에요.
