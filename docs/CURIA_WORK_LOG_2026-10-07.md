## 수행한 변경

| 영역 | 변경 내용 |

| 시장 데일리 | 코스피·코스닥·코인·ETF에 기존 시장 온도 인포그래픽을 재사용. 기존 전문가 11명의 개별 판단과 레드팀을 포함한 12차례 토론 구조를 적용했다. 기존 토론 렌더러·질문 입력·전문가 선택을 재사용했다. |
| 공개 범위 | 무료 요약과 유료 상세·질문을 구분했다. 상세 분석은 암호화 저장하고 API에서도 요금제 권한을 검사하도록 연결했다. Plus 상세 열기는 10크레딧, Pro/Max/alpha 등은 기존 권한 정책을 사용한다. |
| AI 생성 | 시장 리포트 v4 스키마와 전문가·토론·근거 번호 검증 추가. 구조화 출력 설정을 output_config.format으로 변경. 지원하지 않는 발언 분류는 가정으로 표시하고 자료 공백에 기록한다. 토론의 근거 부족 입장은 중립으로 정규화한다. |
| 요약 디자인 | 공통 색상 AI 요약 카드 적용. 종목 화면의 “시장 한눈에”와 “오늘의 요약 · 어제 대비 바뀐 점”을 제거했다. |
| 최신 리포트 표시 | AI 작성일과 가격 기준일을 구분하고, 당일 작성 리포트에 불필요한 최신 리포트 생성 안내가 나오지 않도록 수정했다. 오래된 비동기 응답·캐시가 새 리포트를 덮는 상황도 방지했다. |
| 차트 봉 선택 | 기간 선택과 봉 주기 선택은 구분하되 중복 봉 메뉴를 통합했다. 분봉을 일봉 앞에 두고 1·5·15·60분을 펼쳐 고르게 했다. 주식의 실시간 가격 봉 선택은 제거하고 코인의 실제 체결 틱은 유지했다. |
| 주봉·월봉 | 정렬·중복 제거 후 실제 일봉 OHLC를 합산하고 거래량을 더한다. 시작 경계 주·월의 봉을 포함하며, 일봉 보조지표·가격선·빈 패널이 다른 봉 화면에 남는 문제를 수정했다. |
| 시나리오·게이지 | 시나리오 전망을 지표·레이어 메뉴로 이동하고 기본 숨김 및 설정 저장·계정 동기화를 적용했다. 모멘텀 게이지를 기간별 기술 신호 게이지와 같은 시각 형식으로 맞췄다. |
| 전략 기록 | 챔피언 대결의 전략 행을 누르면 해당 전략의 매매 기록이 펼쳐지도록 변경. 별도 전체 매매 기록 카드는 제거했다. |
| 메뉴·헤더 | 분석 메뉴 아래 기술·전략·수급·실적의 독립 하위 메뉴를 배치했다. 모바일 상단 종목명·가격·등락률·계정 버튼 잘림을 수정했다. |
| 테마 정렬 | 테마 목록에 정렬 기준과 방향 버튼 추가. 구성 종목은 등락률·거래대금·시가총액·현재가·이름으로 정렬한다. 같은 테마 비교에는 시가총액·오늘 등락률·20일 수익률·이름 및 방향 선택을 추가했다. 결측 값은 마지막에 배치한다. |
| 선정 종목 설명 | 고정 추적·주간 선정·일일 선정의 종류·날짜·이유를 카드에 표시했다. 최근 일일 선정의 홈 추천 우선순위를 높였다. 기존 일일 선정은 주식 5개·ETF 1개·코인 1개를 기본으로 하며 고정·주간 추적과 최근 28일 리포트 종목을 제외한다. |
| 표현 교정 | 시장 리포트에서 개별 코인의 등락을 지원하지 않는 “코인 지수”로 표현하지 않도록 표시 문구를 정리하고 일부 문장 오타를 교정했다. |
