# Alpha v2.1.4 통합 개선 계획

## 완료: v2.1.3

지표 상단 버튼 제거, 단일 지표 차트 표시, 이전 설정과 위치 복원. CI·모바일 화면 검증 및 배포 완료.

## 이번 수정 범위

1. 시나리오: 강세·기본·약세는 가정으로 표시. 성립 근거·촉매와 무효화 조건 구분. 지지·저항을 임의의 전환 가격으로 사용하지 않음.
2. 모바일 운영: 넓은 표를 라벨이 있는 카드로 표시. 긴 이메일·요청 내용·완료·반려 버튼 노출 검사.
3. 전략: 중복 순위표 제거, 챔피언 대결 화면 유지.
4. 홈: 업데이트 배너는 홈 화면에만 표시.
5. 토론: 생각 표시와 발언 사이 간격을 포함한 저장된 토론 재생 복구. 전체 바로 보기 제공, 발언자 필터 없이 전체 발언 유지. 실제 질문 답변은 SSE 스트리밍과 Thinking Orbs 유지.
6. 리포트 실패: 실제 오류를 버리던 처리를 수정. 사용자에게 안전한 오류 분류와 재요청 제공. 실패 응답의 사용량도 비용 계산에 유지.

## 아직 해결 확인이 필요한 항목

- 사용자가 겪은 즉시 생성 실패의 원인: 기존 저장 오류가 일반 문구라 원인 확정 불가. 오류 분류 수정 후 실제 실패 원인을 확인해야 함. 성공 생성이 검증되지 않았으므로 해결 완료로 보고하지 않음.
- 코인 분봉 전환의 연속 클릭·실패 처리.
- 지표 자료 부족 여부 사전 안내.
- 모바일 차트 도구의 노출 우선순위와 높이 축소.

## 검증 기준

타입 검사·전체 테스트, 375/390/768/1280 화면에서 운영 내용과 처리 버튼이 잘리지 않는지, 배너가 홈에만 있는지, 단일 지표·설정 복원·토론 재생과 건너뛰기를 검사. 실제 계정 변경·결제·운영 요청 승인 없이 fixture로 검증.
