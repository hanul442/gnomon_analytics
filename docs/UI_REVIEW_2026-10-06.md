# 지표 탐색 코드 검수 — 2026-10-06

범위: 기술 탭, 지표 바로가기, 차트 설정 저장, 차트에서 돌아가기. 프로젝트 전체 검수는 아닙니다.

## 수정한 문제

- 기술 탭 맨 위 지표 버튼 묶음이 각 지표 본문 링크와 중복됩니다. 상단 묶음을 제거합니다.
- 지표 바로가기가 기존 지표를 유지한 채 새 지표를 추가해 차트가 복잡해집니다. 선택 지표만 켜고 보조 패널·전략 표시·지수 비교를 정리합니다.
- 임시로 지표를 확인하는 동작이 개인 기본 설정을 덮어쓸 수 있습니다. 기존 apply의 restoring 경로를 사용해 임시 선택을 저장하지 않고 돌아갈 때 복원합니다.
- 돌아가기 목적지가 기술 탭으로 고정되어 있고 본문 위치도 바뀝니다. 클릭한 원래 탭과 스크롤 위치를 사용합니다.

## 다음 검수 우선순위

1. 코인 분봉에서 일봉으로 전환하는 비동기 요청의 완료·실패 상태. 연속 클릭과 데이터 실패 시 표시가 섞이지 않는지 확인해야 합니다.
2. 지표별 값이 없을 때 disabled 또는 자료 부족 안내를 본문에 표시해 클릭 전에 상태를 알 수 있게 합니다.
3. 차트 지표·예측·전략·그리기 도구의 모바일 노출 우선순위를 정리해 도구 영역 높이를 줄입니다.

## 검증

CI에서 타입 검사·전체 테스트와 네 가지 화면 폭의 단일 지표 표시, 이전 선택 복원, 개인 설정 유지 및 상단 버튼 제거를 검사합니다.
